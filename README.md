## 📱 Responsive Design

The landing page is designed to adapt to smaller screens.

On mobile devices:

* The hero content becomes vertically arranged
* Service cards become a single-column layout
* The “Why Choose Us?” section becomes a single-column layout
* Navigation links are hidden
* Company names wrap when necessary

The responsive styles are implemented using CSS media queries.
